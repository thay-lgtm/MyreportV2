FIREBASE REAL-TIME DATABASE
ລະບົບ sync ໄປທຸກ device ທັນທີ ~100ms — ສະຖານະ:
⚪ ຍັງບໍ່ໄດ້ຕັ້ງຄ່າ — Offline Mode
📖 ວິທີ Setup Firebase (ໃຊ້ ~5 ນາທີ):
ຂັ້ນຕອນ 1 — ໄປ console.firebase.google.com → Add project
ຂັ້ນຕອນ 2 — ໃນ project → Build → Realtime Database → Create database → Start in test mode
ຂັ້ນຕອນ 3 — Copy Database URL (ຕົວຢ່າງ: https://xxx-default-rtdb.firebaseio.com)
ຂັ້ນຕອນ 4 — Project Settings ⚙ → Service accounts → Database secrets → Show → Copy secret
ຂັ້ນຕອນ 5 — ໃສ່ 2 ຄ່ານີ້ຂ້າງເທິງ → ກົດ "ບັນທຶກ & ເຊື່ອມຕໍ່"
✅ ຕັ້ງຄ່າຄັ້ງດຽວ — ຫຼັງບັນທຶກ ລະບົບຈະດາວໂຫຼດໄຟລ໌ໃໝ່ (ຝັງຄ່ານີ້ໄວ້ແລ້ວ) ໃຫ້ອັດຕະໂນມັດ. ເອົາໄຟລ໌ນັ້ນສົ່ງໃຫ້ໝູ່ ຫຼືອັບໂຫຼດຂຶ້ນ hosting ແທນໄຟລ໌ເກົ່າ — ໃຜເປີດໄຟລ໌ນັ້ນ ຈະເຫັນຂໍ້ມູນອັນດຽວກັນທັນທີ ບໍ່ຕ້ອງຕັ້ງຄ່າອີກ.
